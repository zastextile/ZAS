v23 — LIBRARY FIRST

v23.1 — THE ADOPTION HOLE, CLOSED
  · A part priced ONLY per size used to be refused by adoption, which would
    have left you doing it by hand. It is now adopted, taking the most
    common rate per operation. The only refusal left is a part with no
    active operations at all, which is nothing to adopt.

v24 — ONE OPERATION, ONE ALLOWANCE  (the fraud stop)
  · The cap used to be PER STAGE. A stage's progress is a MIN across its
    operations — correct for reporting, WRONG as a booking limit.

        Singer   200 of 200 done  (complete)
        Overlock  50 of 200 done  (behind)
        stage remaining = 200 - MIN(200,50) = 150

    That 150 belongs to OVERLOCK. Book it against SINGER and Singer read
    350 PIECES ON A 200 PIECE ORDER. Rs 350 paid where Rs 200 was owed.
    The stage total still looked right, and the 150 stayed on offer — so it
    could be taken again, and again.

  · Now every operation is capped by ITS OWN booked total:
        Cutting    ceiling = ordered x per-set
        Stitching  ceiling = what was actually CUT for that part
        Dispatch   ceiling = what was actually finished before it
        remaining  = ceiling - what THIS operation has booked

    Singer -> 0 left, refused by name with the number.
    Overlock -> exactly its own 150, untouched.

  · THE MIRROR BUG IS FIXED TOO. Before, once Singer reached 200 the stage
    read 0 and OVERLOCK COULD NOT BE BOOKED AT ALL. Real work was blocked
    while fake work went through.


WHAT DOES NOT CHANGE
--------------------
  · The expansion you described was already correct and is untouched:
        operation quantity = order quantity x part quantity per set
    100 double bed sets = 100 bed sheets and 200 pillow cases. Singer on
    200 pillow cases is Rs 200. Overlock is Rs 400.
  · Packing is still counted in SETS, capped by MIN(finished / per-set)
    across parts. 200 pillow cases at 2 per set allow 100 sets, never 200.
  · Cutting above the plan is still allowed WITH a reason — that is
    wastage, it is real, and it is recorded and shown on the dashboard.
    Every other stage refuses to exceed.
