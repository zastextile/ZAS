1. THE BUG YOU REPORTED
-----------------------
"in proforma invoice is it not show entry if i do manually — first we
 import via csv then any line if enter by manual so its now show in
 production"

You were right, and here is exactly why.

A proforma line stored only the product NAME as free text. Production had
no code to follow, so every time it needed to know what a line was, it
GUESSED — it compared your typed name against every name in Product
Master and took the closest one, but only if the resemblance scored 55%
or better. Below that it returned nothing, and the line simply did not
appear in production.

A CSV import happened to use names copied from the master, so those lines
scored 100% and always appeared. A line you typed by hand almost never
matched to the letter — so it fell under 55% and vanished. Nothing warned
you. The line was on the proforma, printed correctly, and was invisible
to the floor.

THE FIX: the line now stores the product's CODE alongside the name. Pick
once from the list and the code is written; production follows the code
and never guesses again.

"allow me to write even slight differ name but code backend will be
 remain same"

This is the part worth reading carefully.

Pick a product, then reword the name as much as the buyer needs. The
PRINTED text is yours. The CODE does not move. Under the cell a small
green chip tells you both:

    ✓ Hand Towel 400 GSM   printing your wording

The tick is the code that production follows. "printing your wording"
means the invoice will show what you typed, not the master's name.

Only two things change the code:
  - emptying the cell entirely  -> the line unlinks
  - typing the exact full name of ANOTHER master product -> it links to
    that one instead

Anything else you type is treated as your wording for the product you
already picked.

"can i use control ctrl + s so can i save"

    Enter         DOWN one line, same column — the Excel behaviour
    Ctrl + D      copy the cell above
    paste         a block copied from Excel fills across and down and
                  adds the lines it needs

Beside the Save button a small marker reads "saved" or "● unsaved —
Ctrl+S". Closing the tab with unsaved lines now asks first.

3. THE CHIP HAS FOUR STATES, NOT TWO
------------------------------------
    ✓ Hand Towel 400 GSM
        picked, and the printed name is the master's name.

    ✓ Hand Towel 400 GSM   printing your wording
        picked, and you have reworded it. The link holds.

    not linked
        no code stored. Production will fall back to guessing at the
        name, exactly as the whole system did before v16 — which may
        work, or may drop the line.

    ⚠ product #12 no longer in master — pick again
        a code IS stored, but that product has been removed from Product
        Master. The link is dead. Production is guessing again and you
        need to know.

That last one is why this is worth having: previously a dead link and a
live one looked identical on screen.
